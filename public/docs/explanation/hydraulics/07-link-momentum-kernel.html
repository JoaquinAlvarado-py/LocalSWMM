Link Momentum Kernel ​

The link momentum kernel ​

Each conduit is solved by one of the momentum kernels in DynamicWave.cpp (processManningLink, processDryLink, processForceMainLink), dispatched by momentum category. This section transcribes the Manning (free-surface and closed-conduit) kernel, which is the main one.

Velocity, Froude number, and inertial damping ​

With A¯ the midpoint area and qlast the per-barrel flow from the previous iteration,

v=qlastA¯,|v|≤Vmax=50 ft/s(velocity cap).

For a non-surcharged conduit the Froude number uses the hydraulic depth A¯/W¯:

Fr=|v|gA¯/W¯(0 for a closed conduit within FUDGE of full).

The inertial-damping factor follows the local partial inertia approach (linear blend over 0.5≤Fr≤1):

σ={1Fr≤0.5,2(1−Fr)0.5<Fr<1,0Fr≥1,i.e.σ=clamp(2(1−Fr), 0, 1).

The INERTIAL_DAMPING option overrides this: NONE forces σ=1, FULL forces σ=0 (no inertial terms at all); a closed conduit that is surcharged always has σ=0.

Upstream weighting ​

The pressure and friction terms use upstream-weighted average area and hydraulic radius, reflecting that supercritical flow is influenced only by upstream conditions. With the weighting factor

ρ={σqlast>0 and H1≥H2 (and not full),1otherwise,A¯′=A1+ρ(A¯−A1),R¯′=R1+ρ(R¯−R1).

The six momentum terms ​

The engine evaluates the momentum equation as the six contributions dq1…dq6 (per barrel):

dq1=Δt⋅rough_factor⋅|v|R¯′4/3,dq2=ΔtgA¯′H2−H1L,dq3=2vσ(A¯t+Δt−A¯t),dq4=Δtv2σA2−A1L,dq5=Δt2L[Kin|q|A1+Kout|q|A2+Kavg|q|A¯],dq6=2.5ΔtvL(Qevap+Qseep),

where rough_factor=g(n/1.486)2, the local-loss coefficients Kin,Kout,Kavg are the user's inlet, outlet, and average (loss-weighted) minor-loss coefficients, and Qevap+Qseep is the per-conduit loss rate.

The flow update (per barrel) and its head gradient are

q=qold−dq2+dq3+dq4+dq61+dq1+dq5,dQdH=11+dq1+dq5gΔtA¯′Lbarrels.

The dQ/dH gradient feeds the node surcharge solver (Node continuity, flooding, and surcharge).

Flow limiting and post-processing ​

After the raw momentum update, applyFlowLimits (DynamicWave.cpp:2211) applies, in order:

  1. Culvert inlet control (FHWA HEC-5): if a culvert code is present and the conduit is not full, q←min(q,qinlet).

  2. Normal-flow limit: for an open/free-surface conduit not full, if the slope condition (y1<y2, i.e. the water-surface slope is smaller than the bed slope) or the upstream-Froude condition (Fr1≥1) holds (per the NORMAL_FLOW_LIMITED option), then

    q←min(q, βA1R12/3),

    the Manning normal flow at the upstream depth.

  3. Under-relaxation (iterations >0): q=(1−ω)qlast+ωq with a sign-change clamp to ±0.001.

  4. User flow limit: |q|≤qlimit.

  5. Flap gates: reverse flow through a flap gate is zeroed.

  6. Dry-node check: flow is forced to ±FUDGE if the upstream (downstream) node is dry.

Finally,

Qt+Δt=qbarrels,dlink=min(y¯,yfull),Vlink=A1+A22Lrawbarrels.

Force mains ​

Force mains (a FORCE_MAIN cross-section, always full) use a separate kernel (processForceMainLink) with σ=0 and friction from either the Hazen–Williams or Darcy–Weisbach equation,

dq1=ΔtgSf|v|,q=qold−dq2+dq61+dq1+dq5.
