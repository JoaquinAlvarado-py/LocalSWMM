Dynamic wave routing: governing equations ​

The St. Venant equations ​

The dynamic wave model solves the full one-dimensional de Saint-Venant equations (continuity and momentum):

∂A∂t⏟storage+∂Q∂x⏟convective flux=0,\underbrace{\frac{\partial A}{\partial t}}_{\text{storage}} + \underbrace{\frac{\partial Q}{\partial x}}_{\text{convective flux}} = 0, storage∂t∂A​​​+convective flux∂x∂Q​​​=0,

∂Q∂t⏟local acceleration+∂∂x ⁣(Q2A)⏟convective acceleration+gA ∂H∂x⏟pressure gradient+gA Sf⏟friction=0,\underbrace{\frac{\partial Q}{\partial t}}_{\text{local acceleration}} + \underbrace{\frac{\partial}{\partial x}\!\left(\frac{Q^{2}}{A}\right)}_{\text{convective acceleration}} + \underbrace{gA\,\frac{\partial H}{\partial x}}_{\text{pressure gradient}} + \underbrace{gA\,S_f}_{\text{friction}} = 0, local acceleration∂t∂Q​​​+convective acceleration∂x∂​(AQ2​)​​+pressure gradientgA∂x∂H​​​+frictiongASf​​​=0,

where AAA is the flow area, QQQ the discharge, H=Z+yH = Z + yH=Z+y the hydraulic head (ZZZ conduit invert, yyy depth), ggg gravity, and SfS_fSf​ the friction slope. The friction slope follows Manning:

Sf=(n1.486)2Q ∣U∣A R4/3,U=QA.S_f = \left(\frac{n}{1.486}\right)^{2} \frac{Q\,\lvert U \rvert}{A\,R^{4/3}}, \qquad U = \frac{Q}{A}. Sf​=(1.486n​)2AR4/3Q∣U∣​,U=AQ​.

Finite-difference momentum equation ​

The engine uses an implicit (backwards Euler) finite-difference form. With spatial differences over the conduit length LLL and temporal differences over Δt\Delta tΔt, the flow update at each conduit is

Qt+Δt=Qt+ΔQinertia+ΔQpressure+ΔQloss1+ΔQfriction,Q^{t+\Delta t} = \frac{Q^{t} + \Delta Q_{\mathrm{inertia}} + \Delta Q_{\mathrm{pressure}} + \Delta Q_{\mathrm{loss}}}{1 + \Delta Q_{\mathrm{friction}}}, Qt+Δt=1+ΔQfriction​Qt+ΔQinertia​+ΔQpressure​+ΔQloss​​,

where all geometric quantities are evaluated at the new time t+Δtt + \Delta tt+Δt. The four terms are:

ΔQinertia=2Uˉ(Aˉt+Δt−Aˉt)+Uˉ2 A2−A1L Δt,ΔQpressure=−gAˉ H2−H1L Δt,ΔQfriction=g(n1.486)2∣Uˉ∣Rˉ4/3 Δt,ΔQloss=local (minor) losses and evap/seepage terms.\begin{aligned} \Delta Q_{\mathrm{inertia}} &= 2\bar{U}\left(\bar{A}^{t+\Delta t} - \bar{A}^{t}\right) + \bar{U}^{2}\,\frac{A_2 - A_1}{L}\,\Delta t,\\ \Delta Q_{\mathrm{pressure}} &= -g\bar{A}\,\frac{H_2 - H_1}{L}\,\Delta t,\\ \Delta Q_{\mathrm{friction}} &= g\left(\frac{n}{1.486}\right)^{2} \frac{\lvert \bar{U} \rvert}{\bar{R}^{4/3}}\,\Delta t,\\ \Delta Q_{\mathrm{loss}} &= \text{local (minor) losses and evap/seepage terms}. \end{aligned} ΔQinertia​ΔQpressure​ΔQfriction​ΔQloss​​=2Uˉ(Aˉt+Δt−Aˉt)+Uˉ2LA2​−A1​​Δt,=−gAˉLH2​−H1​​Δt,=g(1.486n​)2Rˉ4/3∣Uˉ∣​Δt,=local (minor) losses and evap/seepage terms.​

Node continuity ​

Conservation of volume at each node assembly (the node plus half of each connected link) requires

∂V∂t=AS ∂H∂t=∑Q,\frac{\partial V}{\partial t} = A_{S}\,\frac{\partial H}{\partial t} = \sum Q, ∂t∂V​=AS​∂t∂H​=∑Q,

with AS=ASN+∑ASLA_S = A_{SN} + \sum A_{SL}AS​=ASN​+∑ASL​ the assembly surface area (the node's own storage surface area plus the half-link surface areas contributed by each conduit). In finite-difference form:

Ht+Δt=Ht+Δt2(∑Qt+∑Qt+Δt)(ASN+∑ASL)t+Δt,H^{t+\Delta t} = H^{t} + \frac{\tfrac{\Delta t}{2}\left(\sum Q^{t} + \sum Q^{t+\Delta t}\right)}{\left(A_{SN} + \sum A_{SL}\right)^{t+\Delta t}}, Ht+Δt=Ht+(ASN​+∑ASL​)t+Δt2Δt​(∑Qt+∑Qt+Δt)​,

i.e. a trapezoidal update of the head using the average of the net flows at ttt and t+Δtt+\Delta tt+Δt.

The dynamic wave solution algorithm ​

Overview: the Picard (successive-approximation) iteration ​

Equations (Eq. eq:mom-update) and the node continuity are solved implicitly over each time step by functional iteration (Picard iteration / successive approximations). The steps, matching the engine's DWSolver::execute (DynamicWave.cpp:1026), are:

  1. initNodeStates — reset per-node accumulators: inflow = 0, outflow = losses +++ negative lateral flow, inflow +++ positive lateral flow; surface area from the storage/ponding geometry; converged = 0, ∑dQ/dH=0\sum dQ/dH = 0∑dQ/dH=0.
  2. computeLinkGeometry — batch-compute the end depths y1,y2y_1, y_2y1​,y2​, midpoint depth yˉ\bar yyˉ​, top widths, areas, and hydraulic radii of all conduits from the current node heads; classify each conduit's flow regime; apply Preissmann-slot overrides where surcharged.
  3. Momentum kernels — solve the implicit momentum equation for each conduit (The link momentum kernel), commit the new flows, and scatter them to the node inflow/outflow accumulators, accumulating ∑dQ/dH\sum dQ/dH∑dQ/dH and the surface-area contributions.
  4. Non-conduit structures — compute pump/orifice/weir/outlet flows (Non-conduit hydraulic structures).
  5. Outfall depths — re-set outfall boundary stages from the current flows.
  6. Node depth update — solve the continuity equation for each node head (Node continuity, flooding, and surcharge); tally the unconverged nodes.
  7. If any node changed by more than the head tolerance and the trial limit has not been reached, mark links whose both end nodes converged as bypassed (their flows are held), and iterate.

Under-relaxation: after the first iteration every updated flow and head is relaxed with ω=0.5\omega = 0.5ω=0.5,

xk+1=(1−ω) xk+ω xrawk+1,ω=0.5,x^{k+1} = (1-\omega)\,x^{k} + \omega\,x^{k+1}_{\mathrm{raw}}, \qquad \omega = 0.5, xk+1=(1−ω)xk+ωxrawk+1​,ω=0.5,

and a sign change in flow is forced through a small nonzero value (q=±0.001q = \pm 0.001q=±0.001).

Convergence ​

A node is converged when both the raw Picard residual and the accepted (possibly Anderson-mixed) movement are within the head tolerance εH=0.005 ft\varepsilon_H = 0.005\ \mathrm{ft}εH​=0.005 ft (default). The routing step converges when no non-outfall node is unconverged. The maximum number of trials is 8 by default (MAX_TRIALS); a step that converges on its last allowed trial is still counted as converged.

Flow classification ​

During geometry computation each conduit is classified into one of seven flow classes (DRY, UP_DRY, DN_DRY, SUBCRITICAL, SUPERCRITICAL, UP_CRITICAL, DN_CRITICAL) based on the end depths and the head relative to the end invert elevations, using the normal depth yny_nyn​ (from the inverse section factor at Q/βQ/\betaQ/β) and critical depth ycy_cyc​ (Outfall boundary conditions). The class drives:

  • the surface-area adjustments for dry/critical ends (Table tab:surfadj),
  • the depth used at the critical end (replaced by min⁡(yn,yc)\min(y_n, y_c)min(yn​,yc​)),
  • the friction-based normal-flow limit.
