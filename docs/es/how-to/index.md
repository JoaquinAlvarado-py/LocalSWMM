# Guías de cómo hacer

Las guías de cómo hacer están orientadas a tareas: sabes lo que quieres hacer, aquí está cómo hacerlo.

- [Ejecutar localmente](01-ejecutar-localmente) — clona el repositorio y sirve la app desde tu máquina.
- [Configurar](02-configurar) — archivos de configuración, variables de entorno y claves de API.
- [Compilar desde fuente](03-compilar-desde-fuente) — recompila el motor WASM y el frontend.
- [Scripts y benchmarks](04-scripts-y-benchmarks) — sondas, generadores de entrada y harnesses de extremo a extremo.
- [Desplegar](05-desplegar) — CI/CD y el pipeline de Cloudflare Pages.
- [Contribuir](06-contribuir) — flujo de desarrollo y convenciones.
- [Solucionar problemas](07-solucionar-problemas) — síntomas, causas y soluciones.
