# How-to guides

How-to guides are task-oriented: you know what you want to do, here is how to do it.

- [Run locally](01-run-locally) — clone the repo and serve the app from your machine.
- [Configure](02-configure) — configuration files, environment variables, and API keys.
- [Build from source](03-build-from-source) — rebuild the WASM engine and frontend.
- [Scripts & benchmarks](04-scripts-and-benchmarks) — probes, input generators, and end-to-end harnesses.
- [Deploy](05-deploy) — CI/CD and the Cloudflare Pages pipeline.
- [Contribute](06-contribute) — development workflow and conventions.
- [Troubleshoot](07-troubleshoot) — symptoms, causes, and fixes.
